# Audit — whole source tree (2026-07-05)

Point-in-time snapshot. **Non-authoritative**: superseded by whatever issues are filed from it; per convention it carries no issue numbers. Performed at commit `5b8ad09` (post-#992 version packages, one day after the 2026-07-04 whole-tree pass at `ae12379`). Every finding filed from the 07-04 pass and the two diff audits has shipped and the issue backlog was **empty at audit start** — zero open issues — so this pass weighs residual and structural findings rather than fresh-code churn.

**Scope:** whole `src/` tree, plus `bin/`, `test/`, `spec/`, `bench/`, `docs/adr/`, `website/`, and the depcruise configs. **Method:** ten parallel dimension reviewers (security-core, security-input-surface, correctness, performance, duplication, accidental complexity, test quality, maintainability, architecture, documentation), each gated against the decided digest (all 37 ADRs — Accepted by default, ADR-0008 superseded by 0018, ADR-0015 Rejected, ADR-0028 superseded by 0033 — plus SPEC/CONTEXT/CONTRIBUTING closed items and the dispositions recorded by the seven prior audit snapshots). All 40 raw findings were cross-referenced against the prior snapshots and the full issue tracker before disposition; contested findings were verified in code.

The trust-critical core is again clean: **correctness returned zero findings** (full byte-math trace of wire, all six layouts, kernel crypto, CLI value parsing, vectors), and security-core found nothing above Low. The two High findings this pass are a docs break (five adapter guides show an import that resolves to `undefined`) and an enforcement gap (the public entrypoint itself has no depcruise rule).

## Open findings (ranked, grouped as filing units)

1. **High (architecture) — depcruise boundary gaps: the public entrypoint, the wire→kernel axis, and two latent rule holes.** (a) No rule in `.dependency-cruiser.cjs` matches `from: src/index.ts`, so a future `export * from "./cli/..."`, an adapter re-export, or `export { registerBrand }` from the root would pass CI silently — defeating ADR-0021's registry-never-public guarantee and ADR-0005's small-sync-root posture. (b) No directional rule bars `src/wire/*` from importing `codecs/_kernel/*`; verified live: `wire/base32.ts` (unlike parse/envelope/uuid/timestamp-bytes/codec-shell) has no `*-imports-allowlist` rule at all, so it alone could import kernel modules uncaught. (c) `adapters-no-internals` uses single-segment `^src/adapters/[^/]+\.ts$`, so any future nested adapter subfolder is unconstrained. (d) `src/depcruise-rules.test.ts` reads as if it enforces the real tree but only exercises fixtures/config-sync; the real gate is the separate CI `pnpm depcruise` step — add a pointer comment. **Direction:** class-level sweep — enumerate every module class without an explicit allowlist rule, add `index-imports-allowlist`, `wire-imports-allowlist` (or wire-no-kernel), broaden the adapters pattern, mirror new rules into the fixture harness. **Disposition: file (ready-agent).**

2. **High (docs) — all five website adapter guides import the Signed codec from the wrong package entry.** `website/src/content/docs/adapters/{express.md:114, fastify.md:116, hono.md:147, nestjs.md:97, graphql.md:65}` show `import { createSignedTimestampId, importSigningKey } from "@smonn/ids"`; the root exports only the Timestamp codec + error/types (closed:ADR-0005 asymmetry) — these exist only in `@smonn/ids/signed`. Copy-pasting any of the five verify examples yields `undefined` at runtime. **Direction:** fix all five; AC must be class-level — grep every website/README snippet for root-import of any non-Timestamp codec symbol. **Disposition: file (ready-agent).**

3. **Medium (complexity/maintainability) — the wrapped/signed layout "byte check" is a fake compile-time guard, plus a coupled bare literal.** `wrapped/layout.ts:15-17` and `signed/layout.ts:14-16` assert `Equals<typeof payloadByteLength, 16>` with comments claiming they prove `lane+tag` / `ts+random+tag` sums to the payload — but the assertion never references those local constants, so bumping `tagByteLength` compiles clean despite the advertised guard. Same file: `wrapped/layout.ts:39,46,51-53` repeats bare `4` (half-lane) at four sites silently coupled to `laneByteLength = 8`. **Direction:** replace the type trick with a module-level runtime invariant check over the actual constants in each layout (TS cannot sum literal types cleanly); derive `laneHalfByteLength = laneByteLength / 2`. **Disposition: file (ready-agent).**

4. **Medium (duplication) — Prisma `createMany`/`createManyAndReturn` hooks are verbatim-duplicated.** `src/adapters/prisma.ts:213-250`: the ~18-line `Array.isArray(data) ? data.map(injectOrValidate) : data != null ? injectOrValidate(data) : args` branch is copy-pasted between the two extension points (the second block is a residual of the recent `createManyAndReturn` addition). A null-handling or error-wording fix lands once and silently diverges in the other. Clears ADR-0014's "substantial shared code" prong at 2 sites. Found independently by two reviewers. **Direction:** local `applyInjectOrValidate` helper closed over `injectOrValidate`. **Disposition: file (ready-agent).**

5. **Medium (duplication/complexity) — opaque-handle boilerplate hand-rolled in all four keyed codecs' `key.ts`, plus key-material idiom drift.** (a) Brand symbol + `WeakMap` + `Object.freeze({}) as Handle` + unwrap-or-throw is repeated in `opaque/key.ts`, `signed/key.ts`, `wrapped/key.ts`, `digest/key.ts` — 4 sites, over the ADR-0014 warrant; ADR-0016's digest fix had to be hand-applied per file. (b) The trivial `brandOfId === undefined` guard triplicated in opaque/signed/wrapped `index.ts` folds in free if touched. (c) `_kernel/key-material.ts:118-135` converts hex errors by pre-validation but base64url errors by catch-wrap that discards the specific reason. (d) `_kernel/bytes.ts:64` `BASE64URL_MAX_LEN = 256` has no derivation comment. **Direction:** generic handle-store factory in `_kernel/key-material.ts` (codec-specific brand types stay local); unify key-decode on decode-then-wrap with the original error attached as `cause` (messages stay non-contractual per ADR-0011); one-line rationale for the length bound. **Disposition: file (ready-agent).**

6. **Medium (test) — keyed-codec layouts have no fixed-byte probes, and three small coverage gaps.** (a) The six `layout.ts` modules are exercised only via round-trip; with keyed-codec conformance vectors deliberately deferred to v2 (closed:ADR-0025 — the *public vector* decision, which local tests do not reopen), a consistent-but-wrong offset change in opaque/signed/wrapped/digest round-trips green and is invisible until the weekly mutation run. Add per-keyed-codec fixed-byte probes under pinned keys/rng. (b) No "different material alone → different digest" test under fixed brand/ns/key (`digest/index.test.ts` varies only structural params). (c) No codec-level `safeParse("")` negative (wire covers it; codec surfaces rely on plumbing staying wired). (d) Under-filling user-supplied `rng` callbacks silently zero-tail — pin the current documented behavior with a test (validation would be a behavior change; out of scope). **Disposition: file (ready-agent).**

7. **Medium (test-infra) — mutation testing can't stop a regression.** `stryker.config.json` has no `thresholds` key and `mutation.yml` is weekly-cron, non-blocking: a deleted assertion merges and ships up to a week before a filed issue appears, and even a mutation-score collapse is silent. **Direction:** genuine trade-off (CI cost of incremental-on-PR vs threshold-break on the weekly run) — maintainer decision; also touches `.github/workflows/`, which forces the human route regardless. **Disposition: file (maintainer decision, presents the trade-off without prescribing).**

8. **Low (performance/consistency) — digest rebuilds its constant HMAC-message prefix per call.** `digest/layout.ts:10-29` re-derives `len32(brand)‖brand‖len32(ns)‖ns` on every `digest()`; the sibling wrapped codec already hoists exactly this via `HmacMessageTemplate`. Mirror the pattern for construction-time precompute. **Disposition: file (ready-agent, low-priority).**

9. **Low (duplication) — CLI positional-overflow check duplicated 7×.** `verbs.ts:108,243,404,443,490`, `commands/convert.ts:21`, `commands/keygen.ts:34` repeat the byte-identical `fail(opts, usageError(\`unexpected argument: ...\`))` idiom; every new verb is a likely 8th copy. Over the ADR-0014 count warrant. **Direction:** `rejectExtraPositionals(opts, positionals, maxAllowed)` in `src/cli/args.ts`. **Disposition: file (ready-agent, low-priority).**

10. **Low (docs) — one-line drift roundup.** README's "Choosing a codec" table labels Opaque only "None (encrypted)" with no unauthenticated-integrity warning (the design is closed:ADR-0004; the README coverage gap is not — SECURITY.md and opaque.md carry it, the most-read page doesn't); CONTRIBUTING.md:62's pre-push list omits the `source-hygiene-lint.mjs` step the hook actually runs; `website/.../cli.md:215-217` ends in a dangling empty code fence. **Disposition: file (ready-agent, batched — trivial doc one-liners).**

## Dropped (with reason)

- **Wire-methods re-enumerated in all six codec constructors; spread `wireMethods()` instead** (duplication Medium) — DROP: the "silent incomplete codec" failure mode is false — every constructor has an explicit return type, so adding a `WireMethods` member is a compile error at each site; the re-enumeration is explicit, safe, and churn isn't warranted.
- **min/maxIdForTime sentinel-fill "triplicated"** (duplication Medium) — DROP after code check: reverse inverts timestamp bytes (own local helper already), signed fills a sub-range excluding the tag lane; only timestamp/reverse are truly mirrored, which ADR-0014's motivating case explicitly accepts at 2 sites.

Consistent with prior drops of same-class micro-opts.

- **Derive `--help` verb grouping from `codecModules[].verbs`** — DROP: the 07-04 pass dispositioned this drift as an ADR-0018 checklist item (shipped); re-raising the code-generation alternative reopens that recorded choice for a cosmetic risk.

## Verified sound

- **Byte math (full trace, zero findings):** base32 accumulator masking correct for all pending-bit states; empty/5/10/16-byte round-trips against vectors incl. all-0x00/all-0xFF; final-char `[048cgmrw]` padding constant correct; timestamp big-endian via `%256`/`*256` with `2^48` guard and NaN rejection; UUID verbatim 128-bit mapping; reverse `~b & 0xff` symmetric with bound-flip; signed/wrapped offsets sum checked by hand (6/11/16; 8+8); wrapped u32/i32/u64/i64 lane extension guards and bigint paths reject −0, non-integers, out-of-range; parse ASCII-only fold (no U+212A aliasing), Crockford o/i/l payload-only resolution; `spec/vectors.json` (v4) structurally matches the code and is enforced as a frozen oracle.
- **Crypto kernel:** HKDF labels distinct per codec/primitive, keys non-extractable, constant-time comparisons everywhere including CLI, no `Math.random`, no secret material in errors/logs (key-decode errors omit values; CLI redacts), length-prefix framing in digest/wrapped messages.
- **Input surface:** no ReDoS (fixed-count anchored patterns), no raw SQL in any ORM adapter, no eval/child_process/proto sinks in `src/` or `website/src`, transport error bodies coarse, `process.env` confined to `cli/key.ts`, playground is a thin client-side pass-through.
- **Tests at large:** every source file covered directly or via co-located suites; full-128-bit bit-flip tamper + wrong-key + rotation coverage on signed/wrapped; injected rng/now seams throughout (zero mocking of crypto/time); vectors suite has bidirectional completeness guards; source-hygiene, depcruise-fixture, and dependabot meta-tests all assert substantively.
- **Architecture/docs:** depcruise clean at HEAD; exports map ↔ tsdown entries ↔ subpaths 1:1 with no orphans; adding a 7th codec still ~4-5 mechanical touch points per ADR-0018; SECURITY.md accurate and thorough (unauthenticated-Opaque, rotation, HKDF primary-secret, truncation false-accept rates); CHANGELOG matches v1.2.3; all stale `IDS_OPAQUE_KEY`-era references confined to historical ADRs; JSDoc complete on the six factories and sampled adapters; zero TODO/FIXME/HACK markers in `src/`.
