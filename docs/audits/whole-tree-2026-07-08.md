## Open findings (ranked, grouped as filing units)

1. **High (docs) — `toJsonSchema().example` is documented as regenerated per call, but it is a static placeholder.** `website/src/content/docs/validation/index.md:104,115,126-129` claims the `example` field is "a real, always-valid canonical ID generated on each `toJsonSchema()` call" / "changes on every call," and shows a fabricated sample `usr_06f80z92d2dbsqqg28t5cy4tqg`. The real `schemaExampleId(prefix)` (`src/wire/invariants.ts:18-20`) returns `prefix + "0".repeat(26)` (e.g. `usr_00000000000000000000000000`), captured once in `wireMethods` (`src/wire/codec-shell.ts:26`) — deterministic and identical on every call. The page also contradicts `codecs/timestamp.md:226`, which documents the real behavior. A reader building snapshot tests, caching, or per-call-uniqueness logic on the doc's claim gets silently wrong behavior. **Direction:** rewrite the `example` section (line 115 table cell + the 126-129 subsection + the fabricated sample) to describe the fixed zero-filled placeholder, matching `codecs/timestamp.md`. Docs-only; `schemaExampleId` determinism is intentional and stays. **Disposition: file (ready-agent).**

2. **Medium (performance) — `verifyIdArgs` verifies GraphQL id args sequentially.** `src/adapters/graphql.ts:137-146` `await`s each arg's `safeVerify` inside a `for...of` loop; each is an async WebCrypto round-trip (HMAC for Signed, AES-decrypt+HMAC for Wrapped). A resolver verifying N id args pays N serial round-trips per request instead of overlapped ones. **Direction (embedded trade-off resolved):** fire all `safeVerify` concurrently via `Promise.all`, then walk the results in codec-map order to throw on the first `!ok` — this parallelizes the crypto **and** preserves today's deterministic first-failing-arg error order and null-skip semantics. ADR-0035 (wrapper existence) is not reopened. **Disposition: file (ready-agent).**

3. **Medium (test) — `validateBrand` charset/anchoring is untested.** `src/codecs/_kernel/brand.ts:3-9` enforces ADR-0001's "exactly three lowercase a–z" wire-prefix contract via `/^[a-z]{3}$/`, but every call-site test only exercises the wrong-length branch. A regression widening the class (`[a-zA-Z]`), dropping an anchor, or changing the count passes the whole suite. **Direction:** colocated `brand.test.ts` (or shared `it.each`) asserting `invalid_brand` throws for uppercase / digit / symbol / whitespace / empty / too-short / too-long / non-ASCII, and no throw for valid `"abc"`. Test-only; ADR-0001 not reopened. **Disposition: file (ready-agent).**

4. **Low (maintainability) — opaque codec internal-consistency nits (batched, one file-disjoint unit).** (a) `src/cli/codecs/opaque.ts:33` carries a stray `key: key!` non-null assertion that siblings `signed.ts:33`/`wrapped.ts:46` omit — the `keyed:true` `InspectSpec` arm already types `key` as `K`, so the `!` is dead and would mask a real `tsc` error if the type widened. (b) `src/codecs/opaque/layout.ts:42` names the binder `createOpaqueLayoutOps`, omitting "Timestamp" unlike its three timestamp-family siblings, though its own doc-comment and public ctor (`createOpaqueTimestampId`) mark it a timestamp variant. **Direction:** drop the `!`; rename to `createOpaqueTimestampLayoutOps` (internal-only, one caller). Digest/Wrapped binders correctly omit "Timestamp" and stay. **Disposition: file (ready-agent, low-priority).**

5. **Low (test) — reverse codec has only happy-path CLI coverage.** `src/cli/codecs/reverse.ts` has one test and zero `edge.test.ts` cases; siblings have 9–25 (bad brand, malformed id, error exit codes, `--json`). A CLI-wiring regression specific to reverse (`keylessTimestampInspect`/`runInspect`) is caught only at the core-codec layer. **Direction:** port the timestamp/digest CLI edge patterns to cover `reverse generate` + `reverse inspect` in `src/cli/edge.test.ts`/`router.test.ts`. CLI-layer only; core reverse coverage is already complete. **Disposition: file (ready-agent, low-priority).**

6. **Low (docs) — two-line website drift roundup (trivial doc one-liners, disjoint files).** (a) `website/.../adapters/fastify.md:105-108`'s shared "IdParamFailure shape" section says the ID lands in `request.params`, but it also covers `idQuery`, which writes to `request.query` (`src/adapters/fastify.ts:275`) — scope the sentence to `idParam`. (b) `website/.../cli.md` (generate section) omits the `-c` short alias for `--count` that `docs/cli-spec.md:52` and `src/cli/verbs.ts:86` both support. **Disposition: file (ready-agent, batched — trivial doc one-liners).**

## Dropped (with reason)

- **`graphql.test.ts:547` tautological `expect(true).toBe(true)` after `@ts-expect-error`** (test Low) — DROP: deliberate repo-wide convention (22 `@ts-expect-error` sites); the pragma **is** the assertion (`tsc --noEmit` enforces it), and rewriting one instance creates inconsistency without adding coverage.
- **No `cli/`-internal directional depcruise rule** (architecture Low) — DROP: speculative, no current violation; the global `no-circular` rule + `knip` already backstop cycles and dead exports, and the reviewer itself rated a cli-layering rule "optional, low urgency." Filing a preventive rule for a stable CLI with no defect is noise.
- **`cli/help.ts:14-18` `usage()` prose verb→codec table nothing verifies** (architecture/docs Low) — DROP: the help text is currently accurate; this is preventive only, and the edit-site cost was already dispositioned as an ADR-0018 checklist item in the 07-04 pass. Re-raising the derive-from-`codecModules[].verbs` alternative reopens that recorded choice for a cosmetic staleness risk.
- **Per-encode fresh scratch buffers in `digest/layout.ts:40-45`, `signed/layout.ts:26-35`, `wrapped/layout.ts:142-147`** (performance) — DROP: single small (<32-byte) allocations per call, explicitly annotated as intentional for concurrency-safety and dwarfed by the `crypto.subtle` op they feed; same class as the previously-dropped `encodeBase32`/DataView-per-lane micro-opts.
- **Prisma `injectOrValidate` per-row shallow spread in `createMany`/`createManyAndReturn`** (performance) — DROP: structurally identical to the closed Kysely `transformResult` per-row `{...row}` clone (same immutable-copy posture); nanoseconds against a DB round-trip.
- **Hand-rolled `timingSafeEqual` → `node:crypto`; length-mismatch early return** — DROP: prior-audit dispositions re-confirmed (deliberate Web-Crypto cross-runtime posture; documented fixed-width precondition, all callers fixed-width). Recurring re-drop across 6+ snapshots.
- **CLI `--key`/stdin/`IDS_KEY` exposure** — DROP: `closed:ADR-0033`, operator self-DoS only; recurring re-drop across 7 snapshots.
- **Express `storeLocal` `Object.defineProperty`; Kysely `idPlugin` dotted-key plain `Error`; `fastTenByteRng` 80-bit harvest; `getOpaqueKeyCryptoKey` naming drift; `decodeBase32` trust-the-type** — DROP: prior-audit dispositions re-confirmed (deliberate postures / `closed:ADR-0011` / CSPRNG-equivalent). All recurring re-drops.
- **Six-codec `index.ts` mirroring, four-codec `key.ts` handle boilerplate, HTTP-adapter `idParam`/`idQuery` triplication, ORM adapter parallelism** (duplication) — DROP: shared logic already factored into `wire/codec-shell.ts`, `_kernel` key helpers, `adapter-types.ts`, and `cli/verbs.ts`; remainder is either below the ADR-0014 warrant or deliberate framework-divergent mirroring (`closed:ADR-0014/0018/0020`).
